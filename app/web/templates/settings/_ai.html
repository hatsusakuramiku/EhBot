{# AI 供应商 tab: the models that may decide a book's path, and the keys behind them. This page is where 「配置时必须验证联通性」 is enforced, so three things are deliberately visible rather than tucked away: * every (供应商, 模型) carries its verification state and the reason the last check failed, because that is the fact that decides whether it can enter the chain; * the chain's order is the configuration -- position 0 is 主力 -- and it can only be edited through the same validator that refuses an unverified entry, so the list on screen is always a list that would save; * no credential is ever rendered. The key list shows a label, a state and a cooldown, never the ciphertext and never a fragment of the plaintext. That is a property of `AiProviderKey`, which carries no secret at all, and this file must not undo it by echoing the submitted value back into an attribute. AI 模式本身在「路径」页开启；本页只管理供应商本身。一个供应商可以只配置 Key 和模型而不进链，模型链可以为空 —— 这些都是中间状态，页面照实渲染，不用红色告警 催一个还在被填写的表单。 #} {# --------------------------------------------------------------- 模型链 #}
