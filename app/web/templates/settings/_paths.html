{# 路径 tab: where files live, and how a book's own path inside the library is composed. Two forms. 运行目录 changes take effect on the next task -- the pipeline reads the paths through a provider callable, so nothing restarts -- but already published files are not moved, and the page says so rather than leaving the operator to discover it. The layout template is `{category}/{artist}/{title}`-style. It is the one setting here that can be written wrong in an interesting way, so 预览 renders it against a sample book and shows the exact relative path that would be created, illegal characters already replaced. Preview is a POST that only reads: it validates and renders, and writes nothing. `validate_library_template` refuses an absolute template, `..`, an unknown placeholder and a template with no `{title}`. The first two are path traversal expressed as a setting, so the preview button is a convenience and never the gate -- saving validates again regardless of what was previewed. #}
